# 双系统(快/慢)架构调研与实施计划

来源:2025-09-03 三路文献调研(快慢双系统 VLA / 表征空间预测世界模型 / 逆动力学与意图条件策略)。
核心构想(用户提出):预测先于动作;预测向量 - 真实向量 = 预测误差(意外);预测的未来视觉向量本质就是意图,动作只是满足意图的手段。这与 ideomotor theory(William James 1890)、主动推理(Friston)、JEPA(LeCun)三线汇流。

## 一、最相关的先例(按可迁移性排序)

### 1. Figure Helix (2025-02) — 快慢双系统的工业设计蓝本
- S2 = 7B VLM @ 7-9Hz,输出**单个连续 latent 向量**(即"意图");S1 = 80M transformer @ 200Hz。
- 条件机制:S2 latent **投影后拼进 S1 的 token 序列**(不是 FiLM)。S1 自己重新编码图像,不依赖 S2 的陈旧特征。
- 训练:端到端 BC,梯度经 latent 从 S1 回流 S2,意图表征是学出来的。
- **关键技巧:训练时给 S1/S2 输入加时间偏移,匹配部署推理延迟** —— 直接适用于我们 1Hz/30Hz 错频。
- https://www.figure.ai/news/helix

### 2. V-JEPA 2-AC (Meta, 2025-06) — 冻结编码器+动作条件特征预测
- 冻结 ViT-g 编码器,只训 ~300M 预测器:block-causal transformer,交错 (特征, 动作, 状态) token。
- 损失:teacher-forcing L1 预测下一帧特征 + **2 步自回归 rollout 损失**(防复合误差)。
- 规划:能量 = ‖预测终态特征 - 目标图特征‖₁,CEM 优化动作序列,receding horizon,只执行第一个动作。
- **无奖励、无像素重建、零样本抓取**。62 小时无标注机器人视频即够。
- https://arxiv.org/abs/2506.09985

### 3. DINO-WM (2024-11) — 和我们前提完全相同
- 世界模型直接建在**冻结 DINOv2 patch 特征**上,离线轨迹训练,MSE,CEM 朝目标特征规划。
- 另有复现研究用冻结 DINOv2-S/384 维验证:特征先 LayerNorm 可稳定预测目标和规划能量面。
- https://arxiv.org/abs/2411.04983 , https://arxiv.org/abs/2512.24497

### 4. 逆动力学作为策略/数据引擎
- **VPT (OpenAI, Minecraft)**:2k 小时有标注数据训 IDM,给 70k 小时无标注视频打伪标签,BC 基础策略再 RL —— "IDM 吃所有数据源"在规模上被验证。https://arxiv.org/abs/2206.11795
- **UniPi / SuSIE / GNM-ViNT-NoMaD**:慢系统生成子目标(视频/图像),逆动力学或目标条件低层策略执行。
- **SEER (ICLR 2025)**:端到端预测式逆动力学,联合预测未来视觉状态+推断动作。https://arxiv.org/html/2412.15109v1
- **LAPO / Genie**:IDM+FDM 对 + VQ 瓶颈,把转移压缩成离散 latent action —— 用 VQ 码本约束"意图不离数据流形"的技巧来源。https://arxiv.org/abs/2312.10812

### 5. 慢系统输出形式的权衡(调研结论表)
| 慢系统输出 | 先例 | 结论 |
|---|---|---|
| **连续特征向量(意图)** | Helix, FuN, GR00T N1, Director | **推荐**。便宜、可端到端、拼 token 即可;需 VQ/余弦度量防退化 |
| 子目标图像 | SuSIE, UniPi | 可解释但生成慢、OOD 脆,2D 俯视场景没必要 |
| 文本/离散技能 | Hi Robot, Option-Critic | 带宽低,需要语言条件低层,不适用 |
| 动作块 | π0, ACT, OpenVLA-OFT | 慢规划器不该浪费容量建模 30Hz 动力学 |

### 6. 其他关键组件
- **BYOL-Explore**:表征空间预测误差同时当世界模型损失+好奇心奖励,超人类 Atari 探索;但 Curiosity in Hindsight (Jarrett 2022) 证明持续随机性下仍失败 → 用**学习进度门控**(误差下降量而非误差本身)或 4-8 个预测器 ensemble 的 disagreement 防 noisy-TV。
- **Director (Hafner 2022)**:manager 输出**离散** latent 目标(categorical VAE),worker 追求 —— 连续 latent 目标易退化,离散码本是已验证解法。
- **FuN (FeUdal, 2017)**:manager 低频率发方向向量,worker 每步执行,内在奖励 = 观测位移与目标的余弦相似度 —— 我们意图-执行器内在奖励的直接祖先。
- **HER / GCSL**:事后重标注(用真实到达的未来特征当意图目标)是执行器冷启动的标准监督;Skew-Fit 警告重标比例 ~0.5,防 hindsight bias。
- **Surprise-Gated Episodic Memory**:预测误差/滑动中位数 超过阈值才写记忆 —— 回答"大窗口装什么"。

## 二、定案架构

2025-09-04 探针审计后修订(冻结 DINO 前提被证伪,全部感知改为从零训练;用户决策:借鉴 DINO 架构不借权重,自回归让视觉中枢自己长出来):

```
共享 stem (30Hz, 视网膜/V1 类比, Early-Conv-Helps-Transformers 依据):
    3×90×126 → conv 3→24 s2 → conv 24→48 s2 (48ch @ 23×32)
    低级特征只学一次, 吃检测+预测双份梯度; 部署端每帧只跑一遍
细流分支 (30Hz, 背侧流/where+motion):
    48→96 s2 → 96ch @ 12×16 → 检测头(辅助) + 细 30 token
粗流分支 (1Hz, 腹侧流/what, 服务器从零预训练):
    48ch 23×32 切 patch → ViT-tiny (掩码帧建模/自回归, 自建语料) → 粗 128 token
时序主干: 4层 RoPE transformer 不变
意图接口(双系统目标态): 慢系统输出意图向量(VQ 量化防离流形),
    快系统逆动力学头 (f_t, z, Δt) → 动作
```

风险预案: stem 用低 lr(双目标耦合时防拉偏), 分叉后各分支独立; 生物对应 = V1 可塑性低于高级皮层。

(以下为 2025-09-03 初版构想记录, 架构目标一致, 感知层前提已更新)
旧记录: 冻结 DINOv2-S → 384维特征 → 双尺度窗口; 慢系统 1Hz 大意图 + 快系统 30Hz 逆动力学。

## 三、分阶段实施(服务器 84GB)

- **Phase 0 执行器预训练(无奖励,吃所有数据)**:事后标注 —— 每个 (t, t+k), k∈{1..30} 随机采样,φ_{t+k} 当意图,监督 π_inv → a_t。数据 = 8万帧脚本 + 观战 + 自对弈。附加 ICM 式前向一致性辅助损失,保住 DINOv2 可能洗掉的动作相关细节。
- **Phase 1 意图先验**:生成式建模 p(z | 历史) 拟合回放中真实到达的 φ_{t+H}(VQ 码本,LAPO/Genie 技巧),保证执行器永远看到流形内的意图。此阶段结束即有"脚本水平但接口干净"的可玩 agent。
- **Phase 2a(首选)优势加权事后标注**:训 V(φ),从行为先验采候选意图,按 V(ẑ) - 可行性惩罚 选优;或 return 条件意图采样(UDRL/DT 式)。稳定、离线友好。
- **Phase 2b(可选)特征空间 visual foresight**:1Hz 下用前向模型做短程 CEM rollout,终态按 V 打分。
- **Phase 2c(可选)意图策略全 RL**:动作 = 意图(低维连续或码本索引),环境步 = H 真实帧,时间抽象 30×,样本效率极高;KL 锚定行为先验防离流形。
- **Phase 3 执行器持续共训**:意图漂移后持续用新 rollout 事后重标注训练,回放数据 ≥50%。

## 四、风险与验证(按优先级)

1. **384维 CLS 是否含精灵位置/血量信息** —— 全部前提。**已审计(scripts/probe_features.py, 9509帧/24局/按局划分)**:
   - 自身位置 ✅ 线性可解码(R² +0.60/+0.40,品红自我环在承重,该接口不可撤)
   - **敌人相对位置 ❌ 不可解码**(CLS 线性/MLP、patch MLP 全部 R²<0)——DINOv2 不变性把 5px 精灵当噪声洗掉,student 瞄准长期半盲,只能靠时序差分猜;这是脚本 bot(硬读状态)稳压 teacher 的独立瓶颈
   - 自身血量 ❌、弹药 ❌ 不可解码(2px 血条/无弹药指示,低于特征分辨率)
   - 教训:8局/1180帧的探针会给出假阴性(样本饥饿+按局划分),n≈1万帧才收敛
   - **对策与终局(2025-09-04 探针 v9-v11,全部 9509 帧/24局/按局划分)**:
     - scale×2 无收益(方案 A 排除,不必涨编码器 FLOPs)
     - 小 CNN 探针(3层conv,90×126 原图):自身位置 R² 0.94-0.96,敌人相对位置 0.41-0.52(从全负救回)——**检测式归纳偏置是敌位的正解**
     - 血量/弹药连原始像素岭回归都读不出:头顶血条是"未知位置测宽度"的检测任务,且绿色血条与草丛撞色——**在 _self_ring 里加固定位置自我面板**(左下角 HP 条+3 弹药点,与品红环同语义同调用点)后:CNN 血量 0.99 / 弹药 0.85,连 CLS MLP 都能读到 0.85
     - **最终结论:细流换可训练小 CNN(90×126,安卓上比 DINOv2-S 便宜一个数量级),DINO 只留粗流做规划;自我状态走固定面板,世界实体走 CNN 检测**
     - 渲染变更(厚血条/弹药点/自我面板)使旧 ckpt 分布失配,采用后需重暖启 BC
2. **离流形意图** —— VQ 码本 + 可达性审计(意图与回放特征的流形距离)。
3. **noisy-TV** —— 学习进度门控或 ensemble disagreement,原始预测误差只作 shaping 不作唯一信号。
4. **hindsight bias** —— 混合 ≥50% on-policy 意图条件 rollout。
5. **多模态逆映射** —— 执行窗口短(≤30帧),意图距离归一化输入。
